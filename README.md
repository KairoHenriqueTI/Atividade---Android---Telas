# Atividade - Android - Telas

Implementação de 7 exercícios de layout Android com Jetpack Compose:

1. **UILabs** - Formulário com Status, Priority, DatePicker e TimePicker
2. **Layout Colorido** - Boxes com cores diferentes
3. **Categories** - Grid com categorias (Woman, Man, Baby, Travel, Tech, Food&Drink)
4. **Chatt** - Login com opções de redes sociais
5. **My Application** - Formulário com First Name, Last Name e Rating (5 stars)
6. **The Caldwell** - Livro com imagem, descrição e ícones sociais
7. **BosViagem** - Menu com navegação (Novas Viagens, Minhas Viagens, Mensagens, Config)

## Tecnologias
- Jetpack Compose
- Material Design 3
- ViewModel + StateFlow
- Kotlin 2.0.0

## Como usar
1. Clone o repositório
2. Abra em Android Studio
3. Clique no menu para navegar entre exercícios
